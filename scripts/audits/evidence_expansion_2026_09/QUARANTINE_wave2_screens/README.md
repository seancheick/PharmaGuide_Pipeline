# QUARANTINE — Wave 2 screening drafts

These files are **triage, not curation**. A screening agent read the shortlist abstracts and
recommended a class per identity. They are kept because the triage is reusable and because the
rejection reasons are worth having; they are quarantined because nothing in them has authority.

- Every fact that reaches a pending context is re-extracted centrally from the live source.
- The QA ledger is `../wave2_screen_qa.json`: PMIDs named outside the identity's own retrieval,
  copied spans, class/content conflicts.
- Live re-verification of every selected PMID is `../wave2_verification.json`.

Do not read a dose, a direction or a population from these files into anything that ships.
