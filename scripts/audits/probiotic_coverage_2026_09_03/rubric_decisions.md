# Rubric review — proposals, not silently applied calibration

Global pillar weights and existing numeric constants are unchanged in this batch.
Correcting a source's direction uses the existing direction multiplier; it does
not establish that the multiplier is clinically calibrated.

## What should change next

1. **Do not equate larger CFU or more species with superior formulation.** The
   current Formulation component still rewards both, while Dose also uses CFU.
   Renaming those points would not resolve the scientific assumption. Compare a
   shadow variant that leaves potency adequacy in Dose, disclosure in Transparency,
   and formulation credit for supported identity/delivery/formulation properties.
   Define applicable maxima before redistributing any removed points.
2. **Separate identity from approval of one native reference — corrected in the
   [2026-09-04 dose follow-up](../probiotic_dose_2026_09_04/README.md).** The original targeted replay
   makes the coupling visible: withholding BB-12's invalid native source leaves
   Ritual's Evidence at 8, but lowers Formulation 14.3→12.5 and Dose 9.5→5.5.
   Total falls 61.8→56.0. This is existing rubric behavior, not new weights, and
   must not be sold as evidence that the bottle's physical quality deteriorated.
   The follow-up separates label-owned identity and potency from source approval
   and removes inferred equal shares. Remaining disclosure overlap and
   potency-size rewards still require the rubric decision in item 1.
3. **Do not populate blanket strain-dose windows.** The current unused native
   applicability interface checks population/form/exposure, not clinical indication
   or concomitant treatment. Before adding real windows, require reviewed
   indication, population, co-therapy, formulation matrix, and discrete studied
   exposure with a declared transfer rule. No 1B–10B continuous range inferred
   merely because two arms were studied. All 49 currently have no such record.
4. **Keep coverage separate from confidence and score.** The accompanying coverage
   report records what was searched and remains unresolved. No invented coverage
   percentage or high/moderate/low label is added to the app. An incomplete search
   is not negative research, and a high-quality null trial is not a poor-quality
   study. Existing score confidence remains unchanged as a formula.
5. **Before adding an independent backbone replacement, test its ownership path.**
   The current generic-strain join also requires native review acceptance. Neither
   held strain currently has an independent backbone entry, so no existing valid
   match is lost here. A future valid replacement must not silently remain blocked
   by the old native source hold; resolve its canonical source approval and pin
   the end-to-end matching test as part of that curation batch.

## Review gate before changing weights or calling rankings validated

Use the existing blinded benchmark protocol; don't replace it with an arbitrary
100–150-product quota. Its independent reviewer/protocol prerequisites are still
open. The 42-label replay covers engineering boundaries; it is not a blinded
clinical benchmark. Record rank agreement, disagreements by pillar and archetype,
and reasoned adjudication. No target score for Seed or any competitor.

Native source replacements for BB-12/Bi-07 require the registry's clinician review;
no AI-assisted identity/content check is labeled as that approval. The cited
research candidates can reduce reviewer effort but cannot supply human sign-off.

Phase 3 is **label-photo extraction into human-reviewed drafts**, not automated
literature ingestion. It can proceed independently while these clinical/rubric
decisions remain open. The next expensive rebuild should wait until the desired
rubric scope has been decided, so it is not immediately repeated.
